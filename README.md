# Git Docs demo repository

Sample documentation used to demonstrate and test
[Git Docs for Confluence](https://marketplace.atlassian.com/), which publishes
Markdown from a GitHub repository as native Confluence pages.

Everything under [`docs/`](docs/) is meant to be synced. It deliberately uses the
Markdown features real documentation sets rely on: front matter, GitHub alerts,
fenced code, relative links with heading anchors, nested folders, images, tables,
task lists, collapsible sections and a Mermaid diagram.

To try it: connect `https://github.com/Sami-Al-Arnaout/git-docs-demo` in the app,
set the source folder to `docs`, leave the token empty (this repository is public),
choose a space and press **Sync now**.
